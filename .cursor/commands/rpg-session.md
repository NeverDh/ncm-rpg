# RPG — contexto inicial (`/rpg-session`)

Comando de projeto em `.cursor/commands/`. Use antes de uma tarefa grande ou em chat novo.

Faça **antes** de responder ao pedido que o usuário escrever na mesma mensagem (ou na seguinte):

1. Ler `AGENTS.md` na raiz do repositório (use a ferramenta de leitura de arquivos se necessário).
2. Ler `index/PROJECT_INDEX.md`.
3. Ler o arquivo mais recente em `handoffs/` (ordenar por nome/data no nome do arquivo).
4. Se a tarefa for técnica: ler `architecture/ARCHITECTURE.md` e `docs/MODULES.md`.

Resuma em 3–5 bullets o estado atual e as pendências visíveis nos handoffs. Em seguida execute o pedido do usuário seguindo `AGENTS.md` (handoff ao final se for trabalho substancial: §6 no chat → **aprovação do dono** → arquivo em `handoffs/`). PRODUCT/ANALYST/design não editam código (`AGENTS.md` §7.1).
